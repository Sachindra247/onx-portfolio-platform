# OnX Portfolio Platform

Internal web application for event management and certification tracking.

## Technology stack

- React
- TypeScript
- Vite
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server / Azure SQL
- Microsoft Entra ID
- Azure

## Current modules

- Certification tracking
- Event portfolio management
